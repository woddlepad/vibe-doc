# AgentClinic MedQA (extended)

`agentclinic_medqa_extended.jsonl` is copied unchanged from
[SamuelSchmidgall/AgentClinic](https://github.com/SamuelSchmidgall/AgentClinic)
at commit `b6fbe22300e99a267a7ac94eaa465ab552eef741` (MIT, see `LICENSE.txt`).

215 USMLE-derived OSCE cases. Each has a patient script (`Patient_Actor`),
exam findings, test results, and a `Correct_Diagnosis`.

Splits live in `../splits.json` and are built by `rsi cases --rebuild`.
